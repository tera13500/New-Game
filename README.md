# Elevator Safety Tycoon v1.1.9

엘리베이터 2대를 운영하며 안전/점검/민원/만족도를 관리하는 데스크톱 시뮬레이션 게임입니다.
플레이어는 건물 운영 책임자로서 고장을 줄이고 일일 목표를 달성해 예산과 안전 지표를 유지해야 합니다.

## 1.1.9 핵심 개선
- 타이틀 화면 강화: 게임 소개/역할/목표/루프를 시작 화면에서 바로 이해 가능
- 튜토리얼 개선: 화면 영역 하이라이트 + 실습 단계(정기점검) 포함
- 메인 UX 개선: 액션 버튼 비용 표기, 예산 부족 시 비활성화, 우측 패널 섹션화
- BuildingView 강화: 층 구분선/샤프트 프레임/카 외형/대기량 도트 시각화
- 이벤트 다양화: 랜덤 이벤트를 10개 이상으로 확장 (major/minor/info 유지)
- 스타일 정리: 픽셀 감성 팔레트와 테마(`themes/PixelTheme.tres`) 적용

## 핵심 플레이 루프
1. 상단 카드와 BuildingView로 현재 상태 확인
2. 정기점검/예방정비/긴급수리/업그레이드/안내강화 중 액션 선택
3. Major 이벤트는 팝업으로 판단, Minor/Info는 최근 로그에서 확인
4. Day 리포트로 목표 달성 여부와 핵심 포인트 점검

## 시작 흐름
- 타이틀에서 `튜토리얼 시작` 또는 `바로 시작` 선택
- 튜토리얼 중에는 라운드/이벤트 진행이 정지됨
- 튜토리얼 종료 시 자동으로 Day 운영 시작

## 실행 방법 (Godot 4.6.x)
1. Godot 4.6.x로 프로젝트 열기
2. 메인 씬: `scenes/TitleScreen.tscn`
3. 실행 후 시작 모드 선택

## 주요 파일
- `project.godot`: 버전/실행 씬/테마 설정
- `scripts/Main.gd`: 라운드 흐름, 튜토리얼, 로그, 팝업 제어
- `scripts/EventManager.gd`: 이벤트 풀/등급 구성
- `scenes/Main.tscn`: 메인 HUD, 우측 패널, 튜토리얼 오버레이
- `scenes/components/BuildingView.tscn`: 엘리베이터 운영 뷰
- `scenes/components/ActionPanel.tscn`: 비용 표시 액션 버튼
