# Elevator Safety Tycoon v1.1.11

Godot 4.6.x 기반 데스크톱 운영 시뮬레이션. 2대의 엘리베이터를 관리하며 안전/만족/민원/예산을 균형 있게 지키는 픽셀 감성 타이쿤입니다.

## v1.1.11 핵심 변경
- 버전 전면 갱신: 타이틀/메인/프로젝트 설명을 1.1.11로 통일.
- BuildingView 강화: 선택 호기 프레임, 문 상태(운행/고장/점검중) 애니메이션, 혼잡 도트 밀도 표현 개선.
- 튜토리얼 하이라이트 개선: 오버레이 부모를 투명화하고 4개 dim rect만 사용해 실제 포커스 밝기 유지.
- 비용/상수 정리: 고장 외주비(3800)를 `GameBalance.ACTION_COSTS.fault_outsource`로 통합.
- 상태 의미 분리: `inspecting` 상태 추가로 `inspection_due`와 의미 충돌 해소.
- 플레이 완성도 강화: 속도 버튼(1x/2x/3x), 게임오버 팝업, 마일스톤 목표(예산/민원) 추가.

## 시작 흐름
1. 타이틀에서 `튜토리얼 시작` 또는 `바로 시작` 선택
2. 튜토리얼은 하이라이트 + 실습(정기점검/호기선택) 후 자동 종료
3. Day 운영 시작 → 이벤트 대응 → Day 리포트 확인

## 핵심 플레이 루프
1. 상단 카드/중앙 BuildingView로 위험 신호 확인
2. 액션 패널에서 비용을 보고 선택 (정기점검/예방정비/긴급수리/업그레이드/안내강화)
3. 이벤트 대응 (major 팝업, minor/info 로그)
4. 리포트와 마일스톤으로 다음 Day 전략 조정

## 이벤트 구조
- **major**: 즉시 선택이 필요한 핵심 이벤트
- **minor**: 자동 처리 + 로그 반영
- **info**: 긍정/중립 피드백

## Day/난이도/장기 동기
- 기본 Day 길이: 14 tick
- 진행 압박: Day가 증가할수록 수요/마모/위험 누적 증가
- 장기 목표: 무고장 streak + 예산 150,000 유지/민원 0 유지 목표 추가
- 실패 흐름: 경고 구간 → 임계치 도달 시 게임오버

## 픽셀 폰트 적용 (즉시 적용 구조)
저장소는 라이선스 이슈로 폰트 바이너리를 포함하지 않았습니다. 대신 파일 1개만 넣으면 즉시 전체 UI에 적용됩니다.

1. 권장 폰트: 한글 지원 픽셀 폰트(예: Galmuri 계열, SIL OFL 라이선스 확인 필수)
2. 폰트 파일명: `pixel_ko.ttf`
3. 폰트 위치: `assets/fonts/pixel_ko.ttf`
4. 적용 범위: 타이틀/버튼/카드값/로그/배지/팝업 포함 전체 Theme 계층 자동 적용

## 실행 방법
1. Godot 4.6.x로 프로젝트 열기
2. 실행 씬: `scenes/TitleScreen.tscn`
3. Play
