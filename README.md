# Elevator Safety Tycoon v1.2.0

Elevator Safety Tycoon 1.2.0은 **Modern Clean Simulation** 방향으로 리부트된 2D 운영 시뮬레이션 게임입니다.
플레이어는 **관리주체의 승강기 안전관리자**로서 자체점검, 보수, 이용자 안내를 통해 건물 승강기 2대를 안전하게 운영합니다.

## 게임 소개
- 장르: 운영/관리 시뮬레이션
- 역할: 관리주체(승강기 안전관리자)
- 핵심 지표: 예산, 안전도, 이용자 만족도, 자체점검 이행률, 민원
- 목표: 운행중지 최소화, 안전 확보, 민원 억제, 지속 가능한 운영

## 핵심 플레이 루프
1. 상단 카드와 BuildingView로 현재 위험 신호 확인
2. 액션 바에서 조치 선택(자체점검/예방정비/긴급보수/유지관리업체 호출/안전안내 강화/설비개선)
3. 운영 알림(Event) 판단 및 후속 조치
4. Day 종료 리포트 확인 후 다음 Day 전략 결정

## 주요 액션 구조
- **자체점검**: 일상 안전관리 핵심 행동, 점검 중 단기 운영 불이익 존재
- **예방정비**: 장기 마모/위험 완화
- **긴급보수**: 즉시 위험 대응, 고비용
- **유지관리업체 호출**: 외부 대응, 신속하지만 비용 부담
- **안전안내 강화**: 민원/이용자 행동 리스크 완화
- **설비개선**: 장기 성능 투자

## 자체점검 / 정기검사 / 유지관리업체 개념
- 자체점검: 관리주체의 일상 이행 행동
- 정기검사: 이벤트/일정 관리 관점의 수검 준비 요소
- 유지관리업체: 외부 보수 대응 주체

## 시작 흐름
1. 타이틀에서 `튜토리얼 시작` 또는 `바로 시작` 선택
2. 튜토리얼: 역할 안내 + 핵심 UI 설명 + 실습(자체점검/호기 선택)
3. 운영 시작 후 Day 단위로 리포트와 목표를 갱신

## 난이도 / 마일스톤 / 게임오버
- Day 길이: 16 Tick
- Day 진행에 따라 수요/마모/위험 압박 증가
- 마일스톤: 무고장 연속, 자체점검 우수 이행 등
- 게임오버: 예산 소진 / 안전도 임계치 하락 / 민원 폭주
- 속도 조절: 1x / 2x / 3x

## 실행 방법
1. Godot 4.6.x로 프로젝트 열기
2. 실행 씬: `scenes/v120/TitleScreen.tscn`
3. Play
