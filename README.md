# Elevator Safety Tycoon v1.1.12

Elevator Safety Tycoon은 공공 안전 운영을 주제로 한 현대적 HUD 스타일의 운영 시뮬레이션 게임입니다.
플레이어는 2대의 엘리베이터를 관리하며 예산·안전·민원·만족도의 균형을 유지해야 합니다.

## v1.1.12 핵심 변경
- 그래픽 방향을 **Modern Simulation HUD**로 전환: 더 깔끔하고 전문적인 색/패널/버튼 스타일로 통일.
- BuildingView를 메인 화면으로 강화: 샤프트 대비, 카 상태 표현, 선택 호기 강조, 혼잡도 가독성 향상.
- 우측 운영 패널/최근 로그/팝업 정보 계층 개선: 텍스트 과밀을 줄이고 핵심 행동 유도 강화.
- 튜토리얼 하이라이트 유지 및 온보딩 문구 정리.
- 게임성 보강: 점검/정비/긴급수리의 선택 차이를 명확화하고 마일스톤 조건 확장.
- 실패 흐름 정리: 경고 구간 + Game Over 팝업 + 타이틀 복귀.

## 시작 화면 / 튜토리얼 흐름
1. 타이틀 화면에서 `튜토리얼 시작` 또는 `바로 시작` 선택
2. 튜토리얼은 핵심 UI(자원 카드/BuildingView/액션/로그)를 순서대로 안내
3. 실습(정기점검/호기 선택) 완료 후 Day 운영 시작

## 핵심 플레이 루프
1. 상단 카드와 BuildingView로 위험 신호 확인
2. 액션 선택(정기점검/예방정비/긴급수리/업그레이드/캠페인)
3. 이벤트 대응(major 팝업, minor/info 로그)
4. Day 리포트 확인 후 다음 운영 전략 수립

## 비용 표시 및 액션 구조
- 모든 주요 액션/업그레이드 비용은 `GameBalance.gd`에서 관리됩니다.
- 액션 버튼과 이벤트 옵션은 동일 비용 상수를 참조합니다.
- `inspecting` 상태가 분리되어 점검 중 패널티와 점검 기한 초과를 명확히 구분합니다.

## 이벤트 구조
- **major**: 즉시 판단이 필요한 핵심 이벤트
- **minor**: 자동 처리 + 로그 반영
- **info**: 운영 피드백 이벤트

## BuildingView / 그래픽 방향
- 딥 네이비 배경 + 블루그레이 패널 + 민트/시안 강조의 HUD 팔레트 적용
- 상태별 시각 피드백 강화(`normal`, `busy`, `warning`, `inspection_due`, `inspecting`, `fault`)
- 선택 호기 강조와 우측 패널 연동 강화

## Day 길이 / 난이도 / 마일스톤 / 게임오버
- Day 길이: 14 tick
- Day 진행에 따라 수요/마모/위험 압박 증가
- 마일스톤: 무고장 연속, 고점검 운영, 예산 유지, 민원 제어
- 게임오버 조건: 예산 고갈 / 안전 한계 / 민원 폭주

## 실행 방법 (Godot 4.6.x)
1. Godot 4.6.x로 프로젝트 열기
2. 메인 씬 실행: `scenes/TitleScreen.tscn`
3. 플레이 시작
